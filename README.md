# Data Analytics Project

## Overview
This repository contains data cleaning, formatting, and analysis files for Decodelab Project 1.

## Files Included
* **`Dataset for Data Analytics.xlsx`**: Raw input data used for the analysis.
* **`Decodelab_Project1.xlsx`**: Cleaned dataset including correction logs, standardized dates, and formatted data fields.

## Key Data Cleaning Steps
* Imputed missing numerical values (e.g., Age) using column medians.
* Removed duplicate records based on primary key fields.
* Standardized date fields to ISO 8601 (`YYYY-MM-DD`).
* Cleaned text fields using `TRIM()` and title capitalization.
* Rounded floating decimal values to 2 decimal places.
